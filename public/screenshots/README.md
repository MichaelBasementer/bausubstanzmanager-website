# Screenshots für BausubstanzManager Website

## Platzhalter-Bilder (aktuell verwendet)
- `hero-placeholder.svg` – Homepage Hero (1400×700)
- `mobile-app-placeholder.svg` – Mobile App Screenshot (1000×600)
- `desktop-app-placeholder.svg` – Desktop App Screenshot (1000×600)

## Eigene Screenshots hochladen
1. Erstelle Screenshots von BausubstanzManager Mobile & Desktop Apps
2. Benenne sie wie oben (oder passe die Dateinamen in den .astro-Dateien an)
3. Lade sie in diesen Ordner hoch
4. Ersetze die Platzhalter-Links in:
   - `src/pages/de/index.astro` (Zeile ~27)
   - `src/pages/de/app.astro` (Zeilen ~26-27)
   - `src/pages/[lang]/index.astro` (Zeile ~36)
   - `src/pages/[lang]/app.astro` (Zeilen ~35-36)

## Optimale Größen
- **Hero:** 1400×700px (16:8 Verhältnis)
- **App Screenshots:** 1000×600px (5:3 Verhältnis)
- **Format:** PNG oder JPG (optimiert für Web)
